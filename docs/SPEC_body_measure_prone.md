# SPEC: body_measure_prone — 신체 측정 캘리브레이션 + 포복(엎드림) 몸 눕히기

> 상태: 인터뷰 완료(2026-10-04). 착수 전.
> 선행: W21 VR 자세 시스템(Standing/Crouching/Prone·슈미트 트리거·동적 캡슐·Rising Floor 역보정, `VRPawn`). 이 SPEC 은 그 시스템의 빈 곳(Prone 이 몸을 안 눕힘)을 채운다.

## 배경

지금 `Prone` 은 상태 태그·이동 속도·캡슐 높이(최소 절반 22cm)만 바꾼다. 몸 메시는 yaw 만 돌고 항상 수직 직립이라, HMD 를 낮추면 머리 이펙터는 바닥 22~35cm 로 내려가는데 직립한 몸은 FBIK 로 접어도 거기까지 못 닿는다. 헤드셋에서 "몸이 안 눕고 머리가 제자리까지 못 간다"로 확인(2026-10-04). 헤드셋 없는 PIE 에서 판정 자체는 정상(카메라 50cm → Prone, 35cm → 캡슐 최소, 복귀도 히스테리시스대로).

## 목표

1. **포복 자세**: Prone 이면 몸 메시가 엎드려 눕고, 머리·손이 실제 HMD·손 위치까지 간다. 일어나면 서서히 복귀.
   - 모습 = 엎드려 상체를 약간 들고 팔꿈치로 지지. 몸은 지면과 거의 평행, 머리는 HMD 높이에 맞춰 상체만 들린다.
2. **신체 측정 캘리브레이션**: 사용자 몸 치수를 재서 눕힌 몸의 길이·머리 위치·팔 도달을 사용자 비례로 맞춘다.
   - 측정은 게임 **설정 메뉴의 캘리브레이션 항목**에서 한다(설정 메뉴는 새로 만든다).
   - 방식: 버튼을 누르고 자세를 취하게 해 잰다 — 키·팔 벌림은 HMD·양손, **다리는 컨트롤러를 다리에 대고** 잰다.

## 범위 (변경 파일·시스템)

| 층 | 대상 | 변경 |
|---|---|---|
| C++ | `Core/BP/VRPawn.{h,cpp}` 자세 시스템 | Prone 일 때 몸 메시 눕히기·복귀 보간, 눕힌 몸의 머리·손 이펙터 보정. 자세 코드가 폰에 더 쌓이면 컴포넌트(`UVRPostureComponent` 가칭)로 분리 검토 |
| C++ | 신체 측정(가칭 `UVRBodyMeasure`) | 키·팔 벌림·다리 측정 상태기계, 결과 저장·읽기 |
| UI | 설정 메뉴 | 새로 만든다. 캘리브레이션 항목(시작 버튼·진행 안내·결과 표시·재측정). 월드 UI 규약(`UWorldUIComponent` 상속) 따를 것 |

## 결정 사항

- **측정 항목**: 키(HMD 높이), 팔 벌림(양손 간격, T자세), 다리(컨트롤러를 발목·무릎·엉덩이 등에 대고 버튼). 쓰임은 눕힌 몸의 비례·머리 위치·팔 도달 보정. 아바타 메시 스케일은 지금처럼 1:1 유지 가정(아래 미결).
- **포복 모습**: 엎드려 상체를 약간 들고 팔꿈치 지지. 뒤로 누운 자세는 이번 범위에 넣지 않는다.
- **측정 시작·저장**: 설정 메뉴의 캘리브레이션 항목에서 사용자가 시작. 자동 2초 평균 캘리브레이션(`StartCalibration`)과의 관계는 미결.
- **단계**: M0 스파이크 → M1 눕히기 → M2 측정(아래). **2026-10-08: M2 측정을 먼저 한다**(측정·저장·자동 보정 대체까지, 눕힌 몸 비례 연결은 M1 뒤).
- **(2026-10-08 확정) 측정 절차**: 설정 화면의 캘리브레이션 버튼으로 시작, 4단계 — ① 바로 서기(키 = HMD 높이) ② T자세(팔 벌림 = 양손 간격) ③ 오른손 컨트롤러를 무릎에 ④ 엉덩이(골반 옆)에. 자세 중엔 버튼을 누를 수 없으니 **단계마다 3초 카운트다운 후 자동 측정**. 진행 안내·결과는 캘리브레이션 버튼 글자로 표시(WBP 트리 변경 없음).
- **(2026-10-08 확정) 저장**: 신체 측정 전용 SaveGame 별도 슬롯(설정 슬롯과 분리).
- **(2026-10-08 확정) 자동 캘리브레이션**: 저장된 측정값이 있으면 시작 시 2초 평균 대신 그 값을 쓰고, 없을 때만 자동 폴백.

## 완료 기준 (헤드셋)

- [ ] HMD 를 정자세의 40% 미만으로 낮추면 몸이 엎드려 눕고, 머리가 HMD 위치에 간다.
- [ ] 일어서면 서서히 서 있는 몸으로 복귀하고 발·캡슐이 바닥에 맞는다.
- [ ] 엎드린 채 손을 앞으로 뻗어도 팔이 몸을 뚫거나 꼬이지 않는다.
- [ ] 설정 메뉴에서 캘리브레이션을 하면 서로 다른 신체의 사용자에게 눕힌 몸·머리 위치가 맞는다.
- [ ] 캡슐이 바닥·벽을 뚫지 않는다(엎드린 캡슐 형태).

## 단계

- **M0 스파이크(헤드셋 없음)**: 고정 비율로 몸 메시를 앞으로 눕히고(피벗·방향 정하기) HMD 높이를 낮춰 가며 머리 이펙터와 머리 본의 거리를 PIE 에서 숫자로 잰다. 상체 들림·팔꿈치 지지가 FBIK 만으로 되는지, AnimBP 가 필요한지 판정. 안 되면 방식 재검토.
- **M1 눕히기**: 전이·복귀·캡슐(엎드린 형태)·이동 속도, 헤드셋 확인.
- **M2 측정**: 신체 측정 상태기계 + 설정 메뉴 UI + 저장. 측정값을 M1 의 눕히기 비례에 연결, 헤드셋 확인.

## 미결 사항

- **다리를 컨트롤러로 재는 절차**: 컨트롤러를 어느 지점(발목·무릎·엉덩이)에 몇 번 대는지, 안내 방식. 핸드트래킹 위주로 바뀐(손 위치는 항상 실제 손) 지금 구조에서도 측정 때는 모션 컨트롤러 위치를 직접 읽어야 한다.
- **측정값 저장 위치·형식**: 사용자별 로컬 저장(SaveGame 등)인지. 인터뷰에서 정하지 않았다.
- **설정 메뉴 범위·진입**: 캘리브레이션 말고 무엇을 넣을지, 어떻게 여는지(손 패널 버튼 / 별도 입력). 지금 설정 메뉴는 없다.
- **아바타 스케일**: 측정 결과로 아바타를 다시 스케일할지(과거 결정은 "항상 1:1, 스케일링 제거"). 이번엔 비례 보정만 한다고 가정.
- **기존 자동 캘리브레이션(시작 후 2초 평균)**: 측정 결과가 있으면 대체할지, 없을 때만 폴백으로 둘지.
- **캡슐 형태**: 현재 캡슐은 수직 유지, 최소 절반 높이 22cm. 엎드린 몸의 충돌을 캡슐 눕힘으로 할지 현행 유지할지 M0 에서 결정.
- 엎드림 임계(정자세의 40%, 복귀 45%)가 눕기 쉬운 값인지. 엎드릴 때 HMD 가 바닥에서 보통 얼마인지 사용자 측정 후 조정.
