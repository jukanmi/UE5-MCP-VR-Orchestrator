### 2-8. 메뉴·설정 (2026-10-05, `SPEC_pause_settings` M1·M2, 헤드셋 확인 대기)

헤드셋 없는 PIE 에서는 코드 경로(열기·닫기·재개·설정 전환·볼륨 저장/복원·UI 부착)만 확인했다. 아래는 실제 입력·소리·포인터가 필요한 것.

- [X] **왼손 Menu 버튼** — 누르면 눈앞(약 1m)에 메뉴가 뜨고, 다시 누르면 닫힌다. 머리를 돌려도 메뉴가 따라오지 않고 그 자리에 남는지(멀미 없음).
- [X] **Oculus 시스템 메뉴와 충돌** — 왼손 Menu 버튼이 OS 예약 입력(오큘러스 버튼 길게 누름 등)과 겹쳐 메뉴가 안 뜨거나 시스템 메뉴만 뜨지 않는지. 겹치면 다른 버튼으로 바꾸는 결정 필요(`IMC_VR`).
- [X] **입력 차단** — 메뉴가 열린 동안 ① 스틱 이동·스냅턴·대시·공격·A 상호작용이 안 먹고 ② 쥔 물건은 그대로 들고 있으며 그립을 떼면 놓아지는지 ③ 새로 쥐기(핸드트래킹 접촉 쥐기 포함)가 안 되는지. 월드·NPC 는 계속 움직이는지.
- [X] **포인터** — 오른손 광선으로 재개·설정·뒤로·소리 슬라이더가 눌리고 끌리는지(컨트롤러·핸드트래킹 모두). 인벤토리·손 패널과 겹치거나 가리지 않는지.
- [X] **글자 대비·크기** — 메뉴 글자가 헤드셋에서 읽히는지(버튼 어두운 배경 + 흰 글자). 패널 크기(약 60×46cm)가 적당한지.
- [X] **소리 볼륨이 실제로 변하는지** — 설정에서 슬라이더를 움직이면 효과음(타격음 등)이 즉시 작아지고 0% 에서 무음인지. 로그 `[Settings] 마스터 볼륨 … 적용` 은 나오지만 Quest(OpenXR 오디오 믹서)에서 마스터 서브믹스 출력 볼륨이 실제로 먹는지는 귀로만 확인된다. 안 먹으면 사운드 클래스+믹스 방식으로 교체(SPEC 결정 번복).
- [ ] **저장 유지** — 볼륨을 바꾸고 메뉴를 닫은 뒤 게임을 껐다 켜면 그 값이 유지되는지.
- [X] **리팩토링 회귀** — HUD 패널(왼손 위치·시선 페이드)·채팅 패널(카메라 앞 위치)·아이템 이름표·인벤토리 포인터가 이전과 같은 자리에 같은 모양으로 뜨는지(UI 컴포넌트를 폰 생성자 → `UVRPlayerUIComponent` 런타임 생성으로 옮김). 어긋나면 `PlayerUI` 의 `HUDPanelLocation`·`ChatPanelOffset` 등을 BP_VRPawn 에서 조정.
