# SPEC: npc-bone-collision — NPC 뼈 선분 충돌·밀기

> 상태: **완료(2026-10-02)** — M1~M3 전부, 헤드셋 확인(완료 기준 전 항목 통과). 브랜치 `feat/reality_grab`. 남은 건 아래 미결 사항(무기 손·발·갑옷 뼈 값)뿐.
> 선행: `SPEC_vr_ghost_hand.md` 의 "손으로 NPC 를 밀 수 있다"(`PushNPCWithBlockedHand`, 2026-09-30 미커밋 구현).

## 목표

플레이어 물리 손이 NPC 몸 캡슐(34×88) 하나가 아니라 **뼈 선분 + 반지름**(관절→관절 캡슐)에 막히고, 그 실제 접촉으로 NPC 를 민다.
지금은 손이 몸 바깥 큰 캡슐에서 멈추고(팔·겨드랑이 사이 빈 공간도 막힘), 밀기 판정은 손바닥 주변 구 오버랩으로 "NPC 에 막혔겠지" 추정한다.

## 범위 (변경 파일·시스템)

| 층 | 대상 | 변경 |

| C++ 신규 | 뼈 캡슐 DataAsset 클래스 | 뼈대 계열별 선분 정의 + 메시별 반지름 |
| 에셋 신규 | DataAsset 4개 | 주민(Quaternius Farmer류)·전투형(Warrior·Rogue·Wizard)·UE 마네킹형(Imp·Puglin)·X_Bot |
| C++ 신규 | 에디터 도구 | 메시 정점으로 반지름 자동 채움(Python·MCP 호출) |

| BP | NPC BP 13개 | DataAsset 지정 |

Physics Asset·NPC 메시 충돌·래그돌은 **건드리지 않는다**.

## 결정 사항

- **Physics Asset 안 씀.** 자동 생성 PA 는 정점의 주축 + 경계 상자로 캡슐을 맞춰 머리카락·투구·치마·무기에 끌려 부풀고, 주민 PA 는 바디가 4개뿐이다(루트 뼈 스케일 100 때문에 작은 뼈로 합쳐짐). 2026-10-01 재생성 시도 후 폐기·원복.
- **충돌 모양 = 뼈 선분 + 반지름.** 축은 실제 관절→관절(윗팔 = 어깨→팔꿈치, 몸통 = 골반→목). 끝 뼈(머리·손·발)는 `_end` 뼈 또는 길이 값. 바디 14개: 몸통·머리·좌우 윗팔·아랫팔·손·윗다리·아랫다리·발.
- **판정 = 선분↔선분 최단거리.** 손 모양(손바닥 + 손가락 캡슐 15개, 손바닥 상자는 캡슐로 근사)과 뼈 캡슐 14개. 먼저 NPC 와의 거리로 걸러낸다. 뼈 위치는 매 틱 메시에서 읽어 애니메이션·래그돌·Flinch 를 그대로 따라간다.
- **막힘 = 드라이브 목표점 투영.** 물리 엔진은 이 캡슐을 모르므로, 손 드라이브 목표(앵커)가 뼈 캡슐에 들어가면 목표를 표면 밖으로 밀어낸다(손 모양 전체가 안 겹칠 때까지 반복). 손은 드라이브를 따라 표면에서 멈추고, 실제 손과의 오차가 생긴다. 위치만 밀어내고 회전 반응은 없다.
- **몸 캡슐은 손 채널 Ignore.** 뼈 캡슐 DataAsset 이 지정된 NPC 만. 미지정이면 지금처럼 캡슐에 막힌다(안전 폴백).
- **반지름 = 에디터 도구 자동 채움 + 사용자 수정.** 뼈 선분까지의 정점 거리 백분위값(최대값 아님 — 장식·무기 정점에 안 끌림). 결과를 디버그 드로우로 보며 사용자가 미세조정.
- **저장 = 뼈대 계열별 DataAsset.** 같은 계열은 뼈 이름·선분 정의를 공유하고, 반지름은 체형이 달라 메시별 행으로 둔다(예: Imp·Puglin 은 뼈 이름이 같지만 체형이 다름).
- **NPC 반응 = 루트 밀기 현행 유지.** 수평 스윕 이동(`AddActorWorldOffset`). 바꾸는 건 "무엇에 막혔나" 판정만 — 접촉 뼈·깊이·법선이 직접 나온다. 부위 흔들림·회전은 범위 밖.
- **대상 = 플레이어 손만.** 손에 쥔 아이템·NPC 끼리·플레이어 팔 통과는 범위 밖.
- **디버그 드로우 필수.** 콘솔 변수로 NPC 뼈 캡슐을 그린다(반지름 확인·헤드셋 검증용).

## 완료 기준

- **M1 (데이터)**: 4개 계열 DataAsset 이 메시별 반지름으로 채워지고, 디버그 드로우가 헤드셋 없는 PIE 에서 각 NPC 몸에 맞게 보인다(사용자 육안 확인).
- **M2 (막힘)**
  - 헤드셋에서 손이 NPC 몸 표면(뼈 캡슐)에서 멈춘다. 팔과 몸통 사이 등 빈 공간엔 손이 들어간다.
  - 손끝만 닿아도 멈춘다.
  - NPC 가 걷거나 애니메이션·래그돌 중이어도 판정이 몸을 따라간다.
  - 회귀 없음: 손이 자기 몸에 안 걸림, 래그돌·넉다운·Flinch, 근접 스윙 타격(`TryMeleeHits`), 물건 쥐기, 벽 충돌.
- **M3 (밀기)**
  - 손이 실제로 NPC 뼈에 닿아 막혔을 때만 밀린다. 벽에 막힌 손 옆에 NPC 가 있어도 안 밀린다.
  - 천천히 대고 밀면 NPC 가 밀리고, 벽·지형에서 멈춘다.
  - 구 오버랩 추정 제거(`ponytail:` 주석 해소).

## 단계

- **M1**: DataAsset 클래스 + 반지름 자동 채움 도구 + 디버그 드로우 → 4개 에셋 생성·BP 13개 지정 → 사용자 육안 확인·미세조정.
- **M2**: 선분 최단거리 판정 + 목표점 투영 + 몸 캡슐 손 채널 Ignore → 헤드셋 확인(사용자).
- **M3**: 밀기 판정을 접촉 기준으로 교체 → 헤드셋 확인(사용자).

## 진행 (2026-10-01)

- **M1 완료**(2026-10-01, 사용자 PIE 육안 확인). 다음 M2. `UNPCBoneCapsuleSet`(`Core/Physics/`) — 자동 채움은 에셋 Details 의 `Fill From Meshes` 버튼.

- 선분 끝 규칙: 중간 부위 = 다음 관절, 끝 부위(머리·손·발) = EndBone None → 관절 → 정점 무게중심. Quaternius `_end` 뼈는 방향이 엉망(Blender 꼬리)이라 안 씀.
- 전투형 SkipBones = `Weapon_R`(무기)·`Guard`(Rogue 방패).

- **M2 완료**(2026-10-01 구현·헤드셋 없는 PIE 확인, 2026-10-02 헤드셋 확인 — 완료 기준 전 항목 통과). `AVRPawn::ProjectHandOutOfNPCs`: 손 모양(손바닥 상자 → 긴 축 캡슐 2줄 + 손가락 캡슐 10, 손바닥 바디 기준) ↔ 근처 NPC(메시 경계 구 + 30cm) 뼈 캡슐 선분 최단거리, 가장 깊은 짝만큼 드라이브 목표를 밀어내기 ×4회. `ACombatCharacter::BeginPlay` 가 치수 있는 메시면 몸 캡슐 손 채널 Ignore. 채널 상수는 `Core/Types/CollisionChannels.h` 로 공유.
  - 밀어낼 방향 = 물리 손 쪽(뼈 축 → 물리 손). 실제 손이 축을 넘으면 축 기준으로 비춰서 계산 — 안 비추면 손이 표면을 따라 몸 뒤로 돌아간다(PIE 실측: 몸통 축 10cm 너머에서 앞 +15 → 뒤 −16cm 로 미끄러짐. 비춘 뒤 앞 +17.3cm 고정).
  - PIE 실측(Refugee, 몸통 R 13.1·손바닥 두께 반 2.8): 앵커가 몸통 축 위·축 너머 10cm 일 때 손바닥이 축에서 17.2~17.3cm 에 멈춤. 반대편 표면 밖까지 넣으면 통과.
  - 밀기는 M3 전까지 기존 구 오버랩 추정 그대로, 오차만 실제 손(앵커) 기준으로 넘긴다(옮긴 목표 기준 드라이브 오차는 막혀도 0 에 가깝다).
- **M3 완료**(2026-10-02 구현·헤드셋 없는 PIE 확인·헤드셋 확인 — 완료 기준 전 항목 통과). SPEC 전체 완료. `ProjectHandOutOfNPCs` 가 실제 손 위치에서 가장 깊이 들어간 NPC 를 함께 돌려주고, `PushTouchedNPC` 는 물리 손이 그 표면 목표에서 2cm 안일 때만 들어간 깊이(표면 목표 ↔ 실제 손) 비례로 수평 스윕 이동. 손바닥 주변 구 오버랩·`HandPushProbeRadius` 삭제.
  - PIE 실측(X_Bot, 40cm/s 로 몸통 축 10cm 너머까지): NPC 23.6cm 밀림, 손이 멈추면 깊이 3cm(`HandPushMinError`)에서 멈춤. 바닥에 막힌 손이 NPC 앞 40cm 에 있으면 0cm(옛 구 오버랩이면 최대 속도로 밀렸을 배치). 뒤에 다른 NPC 가 있으면 그 캡슐에 막혀 멈춤.
  - 시험 함정: 앵커를 한 프레임에 수십 cm 옮기면 근접 스윙 타격(`TryMeleeHits`)이 발동해 NPC 가 넘어진다 — 천천히 움직여 시험.
