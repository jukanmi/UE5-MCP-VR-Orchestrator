# SPEC: friction_grip — 마찰 한도 쥐기 + 양손 쥐기

> 상태: M0 완료(2026-10-03). M1 완료(2026-10-04, 헤드셋 확인 — DoList 1-22 전부). M2 구현(2026-10-04) — 헤드셋 없는 PIE 확인, 헤드셋 대기(DoList 1-23).
> 선행: `SPEC_vr_grip_pose.md`(M0~M4 완료 — 접촉 쥐기·끊어지는 고정 제약·관절별 고정 감싸기). 이 SPEC 은 그 문서의 "직접 계산하는 마찰 로직은 만들지 않는다" 결정을 개정한다.

## 배경

지금 쥐기는 손 바디와 아이템을 이동·회전 전부 잠긴 제약으로 붙이고, 전역 고정 임계(`GrabBreakForce` 6000·`GrabBreakTorque` 60000)를 넘으면 끊는다.
그래서 ① 막대 끝을 손가락으로 집어도 수평 그대로 들려 안 꺾이고 ② 쥐는 세기와 상관없이 닿기만 하면 붙으며 ③ 한 손이 쥔 물건은 다른 손이 못 쥔다. 물리적으로 드는 느낌이 안 난다.

순수 Chaos 마찰로 들기(제약 없이 손끝 압착)는 2026-09-30 헤드셋 실험에서 떨림·2.5kg 못 듦으로 폐기됐다. 그래서 제약은 유지하고 **제약이 낼 수 있는 힘·토크를 마찰로 제한**한다.

## 목표

1. **마찰 한도 쥐기**: 쥔 물건은 마찰이 버티는 만큼만 손에 붙어 있다. 넘치는 만큼 미끄러지거나 돈다.
   - 집은 점이 좁으면(핀치) 무게 토크에 져서 집은 점을 축으로 늘어진다. 넓게 감싸면(주먹) 거의 안 돈다.
   - 쥐는 힘을 빼면 뚝 끊기지 않고 스르륵 빠진다. 무거운 물건은 약하게 쥐면 안 들린다.
2. **양손 쥐기**: 두 손이 같은 물건을 쥘 수 있고, 무게가 두 손에 나뉜다. 한 손 마찰로 미끄러지는 무게도 양손이면 든다.

## 결정 사항

- **제약 유지, 상한만 마찰로**: 엔진이 들기를 계속 푼다(떨림 방지). 이동 최대 힘 = `μ·ΣN`, 회전 최대 토크 = `μ·ΣNᵢ·rᵢ`(rᵢ = 쥔 중심 → 접촉점 거리). 접촉 면적은 마찰 크기가 아니라 회전 저항(접촉 분포 r)으로 들어간다 — 쿨롱 마찰은 면적과 무관.
- **미끄러짐 = 목표 재고착**: 드라이브가 상한에 걸려 물건이 밀리면 목표 자세를 현재 자세로 옮긴다(정지마찰 재고착). 안 하면 스프링이 원래 자세로 되돌린다.
- **μ = PhysicalMaterial**: 아이템 메시 물리 머티리얼 Friction × 손 마찰값.
- **N(쥐는 힘)**: 핸드트래킹은 손가락별로 실제 손가락이 고정 관절 각도보다 더 오므라든 각도 × 강성(평활화). 컨트롤러는 그립 트리거 아날로그값.
- **쥐기 판정**: 지금의 기하 판정(핀치·주먹 "사이에 끼었나")은 그대로 두고, 마찰 상한 < 무게면 쥐지 않는다.
- **양손 인벤토리**: 먼저 쥔 손 슬롯만 기록한다. 두 번째 손은 제약만 건다. 던지기·건네기는 기록된 손 기준이고, 마지막 손이 놓아야 드롭된다.
- **손 드라이브 질량 배율**: 양손이면 쥔 물건 질량을 두 손에 나눠 `HeldMassScale` 에 반영.

## 완료 기준 (헤드셋)

- [ ] 핀치로 막대 끝을 들면 집은 점을 축으로 늘어진다(주먹으로 감싸면 거의 안 돈다).
- [ ] 쥐는 힘을 빼면 물건이 스르륵 미끄러져 빠진다.
- [ ] 한 손으로 미끄러지는 물건을 양손으로 든다.
- [ ] 쥔 물건이 떨리지 않는다.

## 단계

- **M0 PIE 스파이크(헤드셋 없음)**: 하네스로 손 바디에 물건을 드라이브 상한 제약으로 매달고, 상한·재고착으로 미끄러짐·회전이 안정적으로 나는지(폭발·떨림 없음) 확인. 막대 끝 매달기 각도·상한별 미끄러짐 속도를 숫자로 남긴다. 안 되면 방식 재검토.
- **M1 한 손 마찰 쥐기**: N 추정(핸드트래킹·컨트롤러 아날로그), μ, 상한 계산, 재고착, 쥐기 판정 조건. 헤드셋 확인.
- **M2 양손 쥐기**: 두 번째 손 제약, 인벤토리·놓기 분기, 드라이브 질량 분배. 헤드셋 확인.

## M0 결과 (2026-10-03, 헤드셋 없는 PIE 90fps)

하네스: 키네마틱 손 상자 ↔ 1kg·60cm 막대, 제약 지점 = 막대 끝(핀치). 이동·회전 Free + 선형 위치 드라이브(강성 10000·감쇠 200) + SLERP 회전 드라이브(강성 1e6·감쇠 5e4), 가속 모드 끔(힘 단위). 재고착 = 스프링 늘어남이 `상한/강성` 을 넘으면 목표를 현재 자세 쪽으로 끌어와 그 길이로 유지. 무게 mg = 980, 끝 핀치 무게 토크 τ₀ = mg·L/2 = 29400 (UE 단위 kg·cm/s²).

발견:
- **회전 토크 상한은 `p.Chaos.Solver.Joint.UseSimd 0` 일 때만 먹는다.** UE 5.5 Chaos 조인트 솔버의 회전 드라이브 SIMD 경로가 MaxLambda 클램프를 안 한다(`PBDJointCachedSolverGaussSeidel.cpp` "Should check MaxLambda eventually"). 기본값 true 에선 토크 0.5τ₀ 도 0.48° 로 그냥 버텼다. 이 값은 물리 씬 생성 때 한 번 읽히므로 런타임 콘솔로 바꾸면 다음 PIE 부터 적용 — `DefaultEngine.ini` 에 넣어야 한다. 선형 드라이브는 SIMD 를 안 타서 기본값으로도 동작.
- **재고착 필수**: 없으면 상한에 걸린 스프링이 하중이 줄 때 원위치로 튕겨 출렁인다.
- **MaxForce 0 = 무제한**(Chaos `SetMaxForce` 가 0 을 "클램프 안 함"으로 씀). 쥐는 힘 0 은 0 이 아니라 놓기로 처리할 것.
- 상한은 축별(X·Y·Z 따로) 클램프 — 선형 마찰 한계가 원이 아니라 상자라 대각 방향은 최대 √3 배까지 버틴다.
- 가속 모드에선 MaxForce 가 역질량으로 나뉜다 → 힘 모드로 써야 `μ·N` 이 그대로 힘이 된다.

## M1 결과 (2026-10-04)

구현: 쥐기 제약 = 이동·회전 Free + 힘 모드 드라이브(강성 질량·관성 × ω², ω 이동 100·회전 40, 임계감쇠), 매 틱 상한 = 마찰 한계, 재고착, 쥔 점이 8cm 넘게 미끄러지면 놓침(`GrabBreakForce`/`Torque`·끊김 이벤트 삭제). `p.Chaos.Solver.Joint.UseSimd=0` 은 `DefaultEngine.ini [SystemSettings]`.
- N: 핸드트래킹 = 애님 인스턴스 `GetFingerSqueeze`(고정 관절보다 더 오므라든 각도 합) × `SqueezeStiffness` 4000, 0.1초 평활. 주먹이면 손바닥이 손가락 ΣN 반작용을 받는다. 컨트롤러 = 그립 아날로그 × `ControllerGripForce` 8000, 회전 팔 4cm.
- 쥔 중심 = 닿은 접촉점들의 가운데(핀치면 두 손끝 사이), rᵢ 최소 0.8cm. μ = 아이템 물리 머티리얼 Friction.
- 쥐기 판정: 접촉 쥐기·컨트롤러 둘 다 μ·ΣN < 무게면 안 쥔다(진열품 구매 판정보다 먼저). 그립을 누른 채 못 들었으면 매 프레임 다시 쥐어 본다.
- 입력: `IA_Grab`·`IA_GrabLeft` Boolean → Axis1D(Down 트리거 작동 임계 0.1), `IMC_VR` 키 `OculusTouch_*_Grip_Click` → `_Grip_Axis`.

헤드셋 없는 PIE(90fps, 그립 주입 `inject_input_vector_for_action` + 모션 컨트롤러 상대 위치 이동, 횃불 1kg·양동이 2.5kg):

|---|---|
| 횃불 무게중심 쥐기 그립 1.0, 30cm 들기 | 따라옴, 기울기 1.7°, 떨림 ≤0.01cm |
| 그립 0.15(힘 한계 840 < 무게 980) | 0.39초 미끄러지다 놓침 |

함정(코드 주석에도 남김):
- **드라이브 목표 좌표 = 아이템 쪽 프레임 기준 손바닥 쪽 프레임.** 반대로 넣으면 목표가 거울 위치에 놓여 드라이브가 운동 방향과 무관하게 한쪽으로 상한만큼 밀어, 평형각 둘레로 감쇠 없이 출렁였다(끝 쥐기 0°↔50°). M0 스파이크는 손이 항등 회전이라 정적 각도만으로는 구분이 안 됐다.
- Chaos 회전 드라이브 강성·감쇠 ×1.5(`p.Chaos.JointConstraint.AngularDriveStiffnessScale`) — 재고착 늘어남 한계는 실효 강성으로 나눈다.

## M2 결과 (2026-10-04)

구현: 두 번째 손은 인벤토리에 기록하지 않고 쥐기 제약만 건다(다른 손이 이미 기록한 물건이면). 기록 손이 놓거나 미끄러져 놓치면 다른 손이 같이 쥐고 있을 때 기록만 그 손으로 넘기고(`MoveHeldItem`) 물건은 안 떨어진다. 마지막 손이 놓을 때만 수납·판매·건네기·던지기·드롭 분기. 쥐기 판정은 이 손 힘 + 같은 물건을 쥔 다른 손 힘(마찰 한계)이 무게 이상이면 통과. 쥔 물건 질량은 두 손이 절반씩 `HeldMassScale` 에 반영. 후보 제외 조건은 "다른 손이 쥔 물건"에서 "이 손이 이미 쥔 물건"으로 바뀜.

헤드셋 없는 PIE(90fps, 횃불 1kg, 두 손 그립 주입):

| 시험 | 결과 |
|---|---|
| 오른손 그립 0.15 단독(한계 840 < 무게 980) | 안 쥔다 |
| 오른손 0.3(1680)으로 쥐고 30cm 들기 | 들린다, 왼손 합류는 기록 없이 제약만 |
| 두 손 모두 0.15(합 1680 ≥ 980) | 한 손으론 못 드는데 두 손으론 계속 든다(1.5초 이상 안정) |
| 기록 손(오른손) 놓음 | 기록이 왼손으로 넘어가고 횃불은 안 떨어짐, 로그 `기록 손 넘김` |
| 마지막 손(왼손) 놓음 | 그때 떨어짐 |

함정: 두 번째 손은 인벤토리 슬롯이 비어 있어서 폰의 "못 든 물건 다시 쥐기"(그립을 누른 동안 매 프레임 재시도) 루프가 매 프레임 다시 쥐었다 — `GetGrabbedItem()` 으로 이미 쥐었는지 확인해 막음.

## 미결 사항

- N 강성(각도 → 힘 환산)·평활화 시간 상수·컨트롤러 그립 힘 — 헤드셋 튜닝(DoList 1-22).
- `UseSimd 0` 전역 비용 — 모든 조인트(래그돌 포함)가 스칼라 경로. 래그돌 여럿 + 쥐기 프레임 시간은 아직 안 잼.
- 회전 강성은 관성 최대축 하나로 — 길쭉한 물건의 긴 축 회전은 실제보다 단단하다(`ponytail` 주석).
- 던지기·건네기·양동이 손잡이 들기는 완료 기준에 넣지 않았다 — 체감이 바뀌므로 M1 에서 같이 본다.
