## 메모

- **인벤토리 수량 기준 두 갈래** — `HasItem`/`GetItemCount` 는 장착분 포함, `RemoveItem`/`GetSlotIndexByItemID` 는 슬롯만. 의도된 비대칭(장착만 하면 보유 false 가 되어 거래·퀘스트가 어긋남). 슬롯에서 실제로 빼는 동작은 `GetItemCountInSlots` 로 판정. `AddItem` 은 전부-아니면-전무. 상한은 `GetEffectiveMaxStack` 경유.
- **BP 직렬화 캐시가 C++ 기본값을 이긴다** — 가시성/활성화를 상시로 바꿀 땐 `BeginPlay` 에서 강제 설정하거나 에셋 재직렬화를 확인할 것(HUDWidgetComp 사례).
- **3D 텍스처 잔여 4건(원인 규명, 조치 미완)** — ① 감폴리 미달: `hy3dgen` `reduce_face()` 가 `preservetopology=True`+`qualitythr=1.0` 하드코딩. `Hy3DFastSimplifyMesh(preserve_border=False)` 2단으로 해결 확인(Glasses 22,138→3,232), **72종 전체 재생성 미실행**(6종만 적용된 혼재). ② 검은 텍셀 58~83%: 6→10뷰로도 못 고침(오히려 악화). ③ 페인트 어두움: 참조 아이콘이 이펙트 얹힌 일러스트라 매핑 실패. ④ 저가중치 뷰 색 환각(Rock 바닥 파랑).
