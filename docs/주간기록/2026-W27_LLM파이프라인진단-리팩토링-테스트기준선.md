## 핵심
프로젝트에 달린 Gemma 12B·e4b 가 역할을 제대로 못 한다는 체감을 **라이브 Ollama 직접 호출 repro** 로 실측 재현해 원인을 특정하고 4종을 고쳤다. ① **Stage2 12B 대사 증발**: 12B(OBLITERATED Q4)가 '정제+plan 동시 출력' 텍스트 지시에서 정제를 거부하고 `[Plan:]` 라인만 뱉음 → `_parse_plan_line` 이 plan 을 떼면 대사가 빈 문자열로 사라짐(재현 4/4). few-shot·rewrite 강제·구조화 출력 전부 정제 거부(8/8) 확인 → **정제를 포기**(Stage1 anti-미사여구 규칙이 이미 담당)하고 Stage2 를 plan 전용 구조화 호출(`_generate_plans`+`PlanBatchResponse` grammar 강제)로 축소. 대사는 Stage1 e4b 출력 그대로. ② **e4b facial 고정 편향**: 같은 전투 상황 3회 반복에 facial 이 Tired/Surprised 로 고정 → 상황 매칭 가이드 1줄로 Angry 3/3 교정. ③ **메모리 요약 오염**: 요약 프롬프트가 영어라 한국어 대화가 영어로 요약돼 컨텍스트 오염 → 한국어화 + 한글 가중 토큰 추정(구식 `len//4` 는 한글 2~3배 과소) + 예산 1000→2000. ④ **action target 자유문자열**: e4b 가 "Strategic Position" 류 해석 불가 target 생성 → UE5 가 `valid_targets`(Player/Self/Enemy+AgentID) 동봉 → Stage1 프롬프트 주입 + target enum grammar 강제로 원천 차단(스모크 3/3).

그 위에 사용자 요청으로 **P1–P5 리팩토링**(behavior-preserving)을 이어 붙였고, 그 과정에서 **tests/ 부패를 청산해 회귀 기준선(pytest 27 passed)** 을 확보했다 — 이제 이런 리팩토링을 pytest 로 즉시 검증 가능. 마지막으로 **NPC 공격 판정**(W26 §, 06-29 구현·미검증)을 기본 Player 로 PIE 검증 완료(HP↓·넉백·NPC 래그돌·스윙당 1회·친선사격 없음; VR 럼블만 미검증).

## 주요 작업

### Gemma 파이프라인 4종 수정 (`ccae0e0` Python, `8143844` C++)
- **Stage2 plan 전용 축소**: `_refine_responses`(정제+plan) → `_generate_plans`(plan-only, `ollama_structured`+`PlanBatchResponse`). 12B rewrite 불능 실측 후 정제 포기. `REFINE_SYSTEM_PROMPT`·`_parse_plan_line`·`_PLAN_LINE_RE` 제거. `npc_plans` dict 계약(goal/steps/relation_snapshot) 유지 → main.py NpcPlans 회신 무변경.
- **e4b facial 가이드**: `DIALOGUE_STRUCTURED_PROMPT`·`DIALOGUE_SYSTEM_PROMPT` 에 "상황 매칭(위협→Angry/Fear, 급보→Surprised, 평온→Neutral), Tired 기본값 금지" 1줄.
- **메모리 요약**(`memory_manager.py`): 요약 프롬프트 한국어화, `estimate_tokens` 한글 가중(HANGUL 0.6/OTHER 0.25), `MAX_TOKENS_PER_NPC` 1000→2000, `ENTRIES_TO_SUMMARIZE` 5→8, e2b `num_predict` 220.
- **valid_targets vocabulary**: UE5 `NPCManager::SendPlayerDialogue` 가 `ActiveNPCs` 키+Player/Self/Enemy 센티넬을 `valid_targets` payload 로 동봉(npc_inventory 패턴 미러). `PromptPayload`→`GesPrompt`→Stage1 프롬프트 주입 + `_dialogue_schema_with_targets` 가 `DialogueActionItem.target` 에 enum 주입(`ollama_structured` `schema_override`). ⚠️ **UE5 빌드·PIE 미검증**.

### P1–P5 리팩토링 (behavior-preserving, `ccae0e0`)
- **P1** `dialogue._vr_get(vr_context, key, default)`: dict|obj isinstance 분기 4곳(voice_transcript·npc_inventory·valid_targets·player_id) 단일화.
- **P3** `llm_factory`: `call_ollama_direct` extract_json=True 데드분기 제거(유일 호출 False)+시그니처 단순화, 미pull·미참조 MODELS 2개(qwen huihui-vl·llama70b) 정리, `re` import 제거.
