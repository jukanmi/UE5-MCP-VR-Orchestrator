# 결정 원장 (Decision Ledger) — W03~W38 교차 추적

주간기록(W03~)에 흩어진 **설계·아키텍처 결정**을 한곳에 모아 "지금도 유효한가 / 언제 바뀌었나"를 추적한다.
주간기록은 append-only 스냅샷이라 옛 주차는 당시 결정을 "현재"처럼 서술 → 그 주만 읽으면 오해 가능. 이 파일이 **단일 현행 기준**.

- **갱신 규칙**: 새 결정·역전 발생 시 해당 표에 행 추가. 역전 시 옛 행은 지우지 말고 §2(역전·진화)로 이동.
- **출처 표기**: `Wnn` = 주차, `(해시)` = 대표 커밋, `§n` = CLAUDE.md 규칙 번호.
- 최종 감사: 2026-09-23 (W38 이관 시). 2026-09-13 (W37). W27~W37 결정 추가, §2 빈 행 4개 기입. silent-drop **0건**(음성 폐기·Repair 제거·v1 롤백 전부 주간기록에 사유 있음).
