# W22 (2026-05-26 ~ 06-01) — NPC 액션 파이프라인 비동기화·중복 제거 리팩토링

## 핵심
NPC 액션 파이프라인의 핵심 결함을 수정 — `STTask_ExecuteSmartAction`이 `ExecuteInteraction` 직후 `OnActionCompleted`를 동기 호출해 이동·몽타주 등 비동기 액션이 즉시 완료 처리되고 큐가 한 프레임에 비워지던 문제를 비동기 완료 모델로 전환. 이어서 코드베이스 중복 구현(danger 계산·GameplayTag·액션상태 리셋)과 파이프라인 잉여(EQS gen)를 정리하는 리팩토링 수행. CLAUDE.md를 StateTree·단일 채널·신규 규칙에 맞게 최신화(로컬, gitignore).
