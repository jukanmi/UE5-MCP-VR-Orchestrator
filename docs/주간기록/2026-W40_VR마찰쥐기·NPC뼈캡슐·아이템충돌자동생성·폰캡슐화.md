## 핵심
① **VR 손이 "닿으면 막히고, 쥐면 마찰로 버티는" 물리 손으로 완성**: 09-30 감싸기(M3)·가운데 마디 캡슐·주먹 쥐기(M4)로 손가락 모양이 물건을 따라가게 한 뒤, 10-04 쥐기 제약을 고정 임계 끊김에서 **마찰 한도 드라이브 상한 + 재고착**(M1)으로 교체. 컨트롤러 그립 아날로그·손가락 오므림이 수직항력 N 이 되고, 마찰 한계가 무게보다 작으면 안 쥐며 미끄러지면 놓친다. 같은 날 Meta 동시 손/컨트롤러 플러그인으로 **손 위치는 항상 실제 손, 컨트롤러는 버튼만**(종전엔 컨트롤러를 쥔 손이 내려놓은 컨트롤러로 순간이동). 양손 쥐기 M2 까지.
② **손↔NPC·아이템 충돌 체계 신설**: NPC 는 Physics Asset 대신 뼈 선분+반지름 DataAsset(캡슐 14개/메시)으로 손이 표면에서 멈추고 닿았을 때만 밀림(M1~M3). 아이템 72종은 외부 무료 에셋으로 전량 교체 후 V-HACD 로 충돌 자동 생성(상자 12·캡슐 16·헐 44) — 30fps 낙하 16종 관통을 CCD 강제로 해소.
③ **거대 폰·NPC 코드 컴포넌트 분리**: VRPawn.cpp 2695 → 약 1400줄(손 `UVRHandComponent`·UI `UVRPlayerUIComponent`·근접 `UVRMeleeComponent`·월드 UI 베이스 `UWorldUIComponent`), NPC 3종 공통부 → `ACombatCharacter`. 디버그 Exec 는 `UVRCheatManager` 로.
④ **되돌린 결정**: 10-02 에 넣은 "빈손 속도 덮어쓰기 + 접촉 시 스프링" 은 10-03 에 선형 드라이브 하나로 통합하며 폐기(떨림 0.026→0.007cm). NPC Physics Asset 재생성도 시험 후 폐기·원복(경계 상자 맞춤이라 부풀고, 루트 스케일 100 때문에 바디 4개).

- **손가락 캡슐을 트래킹대로 물체 속에 옮기면 움직이는 물체에서만 떤다**(09-30): 닿은 마디 관절을 직전 각도에 고정해 해결, 손↔물건 충돌 끄기는 쓰지 않음.
- **U-5 Live Coding 링크 실패**(.lib 는 생성)·**U-6 워크트리 `verify all` Python 16 error 는 환경 문제**(09-30). **U-7 Python 으로 PIE 에 아이템 놓기**·**U-8 `reload_packages` 모달 확인창**·아이템 충돌 수 세기·**아이템 CCD 를 끄지 말 것**(10-03).
- **헤드셋 없는 PIE 손 시험은 컨트롤러 상대 위치를 매 틱 바꿔서**·**월드 위젯 앞면**(양면 위젯 +X→카메라)(10-03).
- **Chaos 조인트 드라이브 상한(UE 5.5)**·**U-9 UBT 한글 따옴표 경로 크래시**·**U-10 콘솔 Exec 는 컴포넌트에 전달 안 됨**·**U-11 빌드 뒤 .cpp 빨강(IntelliSense DB)**(10-04).
