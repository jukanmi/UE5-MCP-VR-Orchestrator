## 핵심

**데이터가 모델을 만든다**는 걸 정면으로 다룬 주. W30 에서 "Sit 233 : Sleep 0" 편향을 발견한 이후, 문제가 그 항목 하나가 아니라 **생성기 구조 전반**에 있다는 판단으로 파이프라인을 다시 짰다.

두 단계로 진행됐다. 전반(08-10)은 **다양성 보강** — 상황 묘사가 3~5개뿐이라 단조롭던 것을 전 카테고리 8개로 늘리고, "매 턴 액션을 강요하는 편향"을 막을 negative 패턴을 4→7종으로, 복합 액션(`multi.yaml`)을 신설했다. 후반(08-15)은 **규모 확장** — 701행(v2) → **3806행**(5.4배)까지 끌어올렸다.

후반 작업은 순탄하지 않았다. API 세션 제한이 ~6배치마다 걸려서 26배치를 한 번에 못 돌렸고, **부분 파일 append 재개 + ID 불일치 감지·삭제·재시작** 패턴으로 총 3회 세션 사이클에 걸쳐 완주했다.

## 주요 작업

### 데이터 다양성 보강 (08-10)

- **intent yaml 전체 `extra_events` 8개로 보강** — lifestyle · combat · common · investigation · social · task · negative 전 카테고리. 상황 묘사 단조로움(3~5개 → 8개) 해소.
- **`negative.yaml` 7종으로 확장**(4→7) — `emotion_only`(순수 감정 반응) · `request_comfort`(위로 요청) · `ambient_observation`(주변 관찰) 추가. **매 턴 액션을 강요하는 편향**을 차단하는 게 목적.
- **`multi.yaml` 신규** — 복합 액션 10종 정의(TurnTo+Comfort, Stop+Scan, Equip+Attack 등). 자연스러운 멀티 액션 발화 커버.
- **`scenario_builder.py::build_multi_scenarios()`** 추가 — multi.yaml 스펙 자동 처리. 새 복합 패턴은 **yaml 한 줄만 추가**하면 되는 구조로.
- **`fill_speech_ollama.py`** — 신규 negative 패턴 3종 특칙 힌트, 기본 모델 `gemma4-e4b-dialogue-v2`, workers 기본 3.
- **산출**: 시나리오 4,800개 → speech 생성(Ollama, 32배치) → 품질 필터 통과 **3,096행**. 고유 대사 3,094개, 중복 2행, 게이트 탈락 0건.

### Stage1 학습데이터 파이프라인 완성 — 3806행 (08-15)

- **규모**: 701행(v2) → **3806행**(5.4배). 34개 액션 + no-action 7종. 26배치(150×25 + 85×1 = 3,814 시나리오 → 8건 length 필터 탈락).
- **파이프라인 구조**:
  ```
  intent yaml (액션별 14~20 발화 × extra_events 8 상황 × 페르소나 다양체)
    → scenario_builder.py  (rules gate 로 금 라벨 생성)
    → Sonnet 서브에이전트 26개  (speech 생성)
    → build_from_generated.py  (병합·검증)
    → stage1_e4b_train_generated.jsonl
  ```
- **세션 제약 대응** — API 세션 제한(~6배치마다 리셋)이 반복돼, 부분 파일 append 재개 패턴 + ID 불일치 감지·삭제·재시작으로 극복. 총 3회 세션 사이클.

## 메모

- **negative 패턴은 "액션 안 하기"를 가르치는 데이터다** — 없으면 모델이 매 턴 무언가 하려 든다. 4→7종 확장은 이 편향을 줄이려는 것이고, 데이터 확장 시 항상 같이 늘려야 한다.
- **파이프라인이 yaml 주도로 바뀌었다** — 새 복합 액션 패턴을 넣을 때 코드를 고치지 않고 `multi.yaml` 만 추가하면 된다. 다음 확장 때 이 경로를 쓸 것.
- **세션 제한 재개 패턴** — 대규모 생성은 중간에 끊긴다고 전제하고 설계할 것. 부분 파일 append + ID 정합 검사가 없으면 처음부터 다시 돌려야 한다.
