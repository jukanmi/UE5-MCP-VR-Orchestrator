# SPEC: posture — 신체 측정 기반 자세 인식 확장 + 몸 연동

> 인터뷰 결정 2026-10-08. 의도·결정만 적는다(구현 세부는 코드가 설명). 상태: ⬜ 착수 전.
> 선행: `SPEC_body_measure_prone` M2 신체 측정(✅ `80f93d31` — 키·팔·무릎·엉덩이 저장). 그 SPEC 의 M0·M1(고정 엎드림 포즈 눕히기)은 이 SPEC 의 M4 로 **대체**한다.

## 목표

1. 플레이어의 실제 자세를 **서기 · 쭈그리기 · 허리 숙이기 · 엎드리기** 4개로 인식한다.
2. 게임 판정은 **측정한 키 대비 높이 비율**로 개인화하고, **HMD(헤드기어) 각도**를 함께 써서 높이만으로 안 갈리는 자세(허리 숙이기)를 구분한다. 몸체는 판정과 별개로 연속 변형한다.
3. 인식한 자세를 이동·캡슐, 은신(적·NPC 시야), 게임플레이 태그에 쓴다.
4. 아바타 몸이 **높이에 맞춰 연속으로 숙여지고 엎드려지게** 한다(고정 포즈 전환이 아니라 HMD 높이·위치를 따라가는 연속 변형).

## 결정 사항

**D1. 자세 4개.** 서기 · 쭈그리기 · 허리 숙이기 · 엎드리기. 기존 enum 의 `Crouching` 은 쭈그리기로 쓴다(이름 유지, 태그 호환). `Bending` 을 새로 추가한다. 의자·바닥 앉기는 HMD 만으로 쭈그리기와 구분이 안 돼(둘 다 상체가 선 채 비슷한 높이) 넣지 않는다.

**D0. 게임 판정과 몸체를 분리한다(2026-10-08).**
- **게임 판정**(이동 속도·캡슐·은신·태그)은 이산 자세 4개 — **측정한 키 대비 HMD 높이 비율** 구간으로 정한다.
- **실제 몸체**는 이산 자세와 무관하게 HMD 높이·위치를 따라 **연속으로** 변한다(D7). 판정 구간 경계에서 몸이 툭 바뀌지 않는다.

**D2. 판정은 키 대비 비율 구간.**
- 서기 → 지금처럼(비율 ≈ 1).
- 약간 낮아지면 쭈그리기.
- 다리를 접어 쭈그려서는 갈 수 없을 만큼 낮으면 엎드리기 — 이것도 비율 임계로 둔다(현재 0.75/0.40 계열에서 출발, 헤드셋 실측으로 조정).
- 기준 키는 측정값(없으면 시작 시 자동 2초 평균) — 그래서 비율만으로 사람마다 개인화된다. 무릎·엉덩이 측정값은 판정이 아니라 **몸 비례(D7)** 에 쓴다.
- 전이마다 히스테리시스(들어가는 값과 나오는 값을 다르게)를 유지해 경계에서 떨지 않게 한다.

**D3. 허리 숙이기는 HMD 피치 + 높이 구간으로.** 다리는 펴고 상체만 숙이면 머리가 아래를 향하고(피치 하향) 높이가 서기보다 조금 내려간다. 높이 비율이 [쭈그리기 진입, `BendRatioMax`(초안 0.93)) 구간이고 HMD 피치 하향이 `BendPitchDownDeg`(초안 30°) 이상이면 허리 숙이기. 복귀는 피치 < `BendPitchUpDeg`(20°) 또는 비율 > `BendRatioMaxUp`(0.95) — 진입보다 느슨하게 둬 히스테리시스. 서서 고개만 숙여 내려다보면 비율이 거의 안 내려가 0.93 이상에 머물러 서기로 남는다. 높이가 쭈그리기 진입 아래면 항상 쭈그리기(높이 우선). (2026-10-08 결정: 캡슐이 매 프레임 HMD 를 따라가 발 대비 앞쪽 오프셋을 직접 잴 수 없고, 머리 이동을 누적하는 방식은 내려다보며 걸을 때 오판해 버렸다.)

**D4. 이동·캡슐.** 자세별 이동 속도·캡슐 높이를 둔다. 허리 숙이기는 서기와 쭈그리기 사이. 엎드리기 캡슐 형태(수직 유지 vs 눕힘)는 M2 에서 결정(미결).

**D5. 은신 = 시야 거리 감소.** 쭈그리기·허리 숙이기·엎드리기일 때 적·NPC 가 플레이어를 볼 수 있는 거리를 자세별 계수로 줄인다(엎드리기 < 쭈그리기 < 허리 숙이기 < 서기). 플레이어 쪽 시야 대상 판정 한 곳에서 처리해 적·아군 NPC 에 모두 적용한다. 자세를 LLM 에 넘기지는 않는다.

**D6. 태그·이벤트 제공.** `State.Posture.*` 태그와 기존 `OnPostureChanged` 델리게이트로 다른 시스템이 자세를 읽게 한다. 그 이상의 게임플레이 용도는 후속.

**D7. 몸 = 높이에 맞춘 연속 변형.** 이전 SPEC 의 "임계 넘으면 엎드림 포즈" 가 아니라, HMD 높이·피치에 비례해 몸이 점점 숙여지고(상체 기울기·골반 높이), 충분히 낮아지면 엎드린 몸이 되도록 연속으로 따라간다. 측정한 다리·엉덩이 비례로 몸 길이를 맞춘다. 방식(메시 피벗 회전 + FBIK 이펙터 vs AnimBP 블렌드)은 M4 스파이크에서 정한다.

## 완료 기준

- **M1** 헤드셋 없는 PIE 에서 HMD 높이·피치를 바꿔 가며 4자세가 측정값 기준 임계대로 전이하고(로그·태그), 측정값이 없으면 폴백 비율로 동작한다. 경계에서 떨지 않는다. 헤드셋: 실제로 쭈그리기·허리 숙이기·엎드리기를 했을 때 그 자세로 인식된다.
- **M2** 자세별 이동 속도·캡슐이 바뀌고 캡슐이 바닥·벽을 뚫지 않는다.
- **M3** 적·NPC 가 쭈그리기·숙이기·엎드리기 중인 플레이어를 서 있을 때보다 가까워져야 발견한다(PIE 거리 비교).
- **M4** 헤드셋에서 머리를 낮추는 정도에 따라 몸이 자연스럽게 숙여지고, 엎드리면 몸이 바닥과 거의 평행하게 눕고 머리가 HMD 위치에 간다. 일어서면 서서히 복귀한다.
- 모든 마일스톤: `sol_pi verify all` 통과. 헤드셋 확인은 DoList.

## 단계 (Milestone)

| M | 내용 |
|---|---|
| M1 | 4자세 판정(키 대비 비율 구간·HMD 피치·높이 구간·히스테리시스), `Bending` 태그, 판정 디버그 로그 |
| M2 | 자세별 이동 속도·캡슐(허리 숙이기 추가, 엎드리기 캡슐 형태) |

## 미결 사항 (작업 중 발견 시 추가)

- 허리 숙이기 피치·높이 구간 임계값(초안: 피치 30° 이상 하향 + 높이 비율 [0.75, 0.93), 복귀 피치 20° 미만 또는 비율 0.95 초과) — 헤드셋 실측으로 조정.
- 판정 비율 구간값(쭈그리기·엎드리기 진입/복귀) — 현행 0.75/0.80·0.40/0.45 에서 출발, 헤드셋 실측으로 조정.
- 몸체 연속 변형에서 무릎·엉덩이 측정값을 어떻게 쓰는지(다리 길이·골반 높이 비례) — M4 스파이크.
- 엎드리기 캡슐 형태(수직 유지 최소 높이 vs 눕힌 캡슐).
- 은신 계수(초안: 허리 숙이기 0.8 · 쭈그리기 0.6 · 엎드리기 0.35).
- M4 몸 변형 방식과 AnimBP 그래프 편집 필요 여부.
