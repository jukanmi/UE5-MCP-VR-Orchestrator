# SPEC: npc-lift-throw — 플레이어가 NPC 끌기·들어올리기·던지기

> 상태: **인터뷰 완료(2026-09-24)**. 근거: `docs/DESIGN_vr_physics_grip.md` 13~16행.
> 선행: `SPEC_vr_ghost_hand.md`(물리 손), `SPEC_vr_grip_pose.md`(breakable constraint 그립).

## 목표

플레이어가 쓰러진 NPC 를 물리적으로 끌고, 들고, 던진다.
스크립트 연출이 아니라 물리 결과로 나오게 한다.

## 범위 (변경 파일·시스템)

| 층 | 파일 | 변경 |
|---|---|---|
| C++ | `NPC/Components/NPCRagdollComponent.{h,cpp}` | 잡힘 상태 추가: 잡힌 동안 안착 감지(`TickSettleDetection`)·기상(`BeginGetUp`) 억제, 놓으면 재개. 팔 부분 물리 블렌드(`Flinch` 패턴 재사용) |
| C++ | `Core/BP/VRPawn.{h,cpp}` | 그립 지점 PD constraint, 릴리즈 시 손 속도 임펄스(`ThrowVelocityScale` 패턴) |
| C++ | 던지기 충돌 피해(자리 미정) | 던져진 NPC 충돌 속도가 임계 이상이면 기존 `TakeDamage` 경로로 피해 |
| 에셋 | NPC 스켈레탈 메시 | 겨드랑이 트리거 존 |

## 결정 사항

- **대상 = 넉다운·래그돌 상태 NPC 만**: 이미 물리 상태라 StateTree·AI 이동과 충돌하지 않는다. 서 있는 NPC 는 잡을 수 없다.
- **잡힌 동안 기상 억제**: 현재 넉다운은 골반 속도가 `SettleSpeedThreshold` 미만으로 `SettleHoldTime` 지속되면 기상한다. 플레이어가 NPC 를 들고 가만히 있으면 들린 채 기상이 시작되므로, 잡힘 상태에서는 안착 감지를 멈추고 놓은 뒤 다시 잰다.
- **한 손 = 끌기만, 들기·던지기 = 양손**: 한 손은 팔·옷을 잡고 바닥에 끈다. 한 손으로 들면 무게중심 브라케팅이 없어 회전하며 미끄러지므로 막는다.
- **겨드랑이 끼워 들기**: 다리는 래그돌로 바닥에 끌리고 상체만 받친다. princess-carry 보다 싸다. 훅 판정은 겨드랑이 트리거 존 + 진입 각도(노멀 내적).
- **"낀" 반응은 근접 게이팅 부분 물리**: 평소 NPC 본은 QueryOnly. 플레이어 손이 가까워졌을 때만 그 팔을 `SetAllBodiesBelowSimulatePhysics` 로 켠다. 상시 켜면 NPC 수만큼 물리 비용이 쌓인다.
- **던지기 = puppet 방식**: 전신 래그돌 + 그립 지점 강한 PD constraint(breakable 아님) + 릴리즈 시 손 속도 임펄스. 관절 토크 계산으로 만들지 않는다. 궤적 품질은 사용자 팔 리치가 좌우한다(물리적 제약).
- **피해 = 충돌 속도 임계**: 던져진 NPC 가 임계 속도 이상으로 부딪히면 속도에 비례한 피해를 기존 `TakeDamage` 경로로 준다.
- **LLM 통지 없음**: 들림·던져짐은 물리 연출만. Envelope 추가 없음. 단 피해는 기존 피격 경로를 타므로 그쪽 기존 보고는 그대로 나간다.
- **attach 없는 순수 접촉 들기는 스파이크로 분리**: 안정성을 계산으로 확답할 수 없다. M3 에서 프로토타입만 하고, 실패하면 constraint 방식 유지.

## 완료 기준

- 쓰러진 NPC 팔을 한 손으로 잡고 당기면 바닥에 끌린다. 한 손으로는 들리지 않는다.
- 양손을 겨드랑이에 넣고 들면 상체가 들리고 다리가 끌린다.
- 들고 가만히 있어도 NPC 가 기상하지 않는다. 놓으면 안착 후 기존 기상 흐름으로 돌아간다.
- 양손으로 들고 휘두른 뒤 놓으면 손 속도 방향으로 날아간다.
- 던져진 NPC 가 벽에 세게 부딪히면 피해를 받고, 살살 놓으면 피해가 없다.
- 서 있는 NPC 는 잡히지 않는다.
- PC VR 90Hz(프레임 예산 약 11.1ms)에서 들기 중 프레임 드랍 없음. Quest standalone APK 는 보류 상태라 기준 아님.

## 단계

- **M1**: 잡힘 상태 + 기상 억제 + 한 손 끌기.
- **M2**: 양손 겨드랑이 들기 + 던지기(PD constraint + 릴리즈 임펄스) + 충돌 피해.
- **M3**: 기술 스파이크 — attach 없는 순수 접촉 들기. 되는지만 판정.

## 미결 사항

1. NPC 질량을 실제 체중으로 둘지, 게임성 위해 낮출지. `SPEC_vr_ghost_hand.md` 물리 손 Max Force 와 맞물린다(너무 무거우면 손이 못 든다).
2. 충돌 피해 속도 임계·비례 계수: PIE 튜닝.
3. 사망(치명 래그돌) NPC 도 대상에 포함할지. 기상이 없으므로 기상 억제는 불필요.
4. 끌기용 한 손 그립 지점: 팔만인지, 옷(Cloth)도 포함인지. Cloth 잡기는 파티클 핀 별도 구현이라 비싸다.
5. 잡고 있는 도중 NPC 가 다른 원인(피격 등)으로 상태가 바뀔 때 그립 해제 규칙.
