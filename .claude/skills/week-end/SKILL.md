## Week End

한 주치 `Done` 을 `docs/주간기록/2026-W##_<핵심주제>.md` 로 **이관**(복사 아님)합니다.
주간기록이 1차 소스, Memo/DoList 는 작업판 — 작업판을 비우는 게 이 스킬의 목적.

### 1. 대상 주차 산정

- ISO 주차, 월요일 시작. `date +%G-W%V` 로 이번 주 확인.
- 기본은 **직전 완료 주차**. 이번 주 마감을 명시하면 이번 주.
- `ls docs/주간기록/` 마지막 파일과 비교해 **빠진 주차가 있으면 오래된 것부터** 순서대로. 한 주 커밋 0건이면 파일 만들지 않고 건너뜀.
- 인자로 주차를 받으면(`/week-end W38`) 그걸 사용.

### 2. 소스 수집 (4개)

| 소스 | 무엇 |
|------|------|
| `docs/Memo.md` `## Done` | 해당 주 날짜가 붙은 항목 — 본문의 뼈대 |
| `.agents/rules/pitfalls.md` | 그 주에 추가·갱신된 항목(`git log -p --since` 로 확인) → `## 메모` 섹션 |
| `docs/DoList.md` `## Done` | 해당 주 에디터·PIE 작업 → 본문 분류 중 하나 |
| **`git log`** | **커밋 기록이 뼈대.** `## 커밋` 표 + 본문 각 항목의 대표 해시 |

커밋 기록은 **반드시** 넣습니다. Memo/DoList Done 은 "무엇을 왜"만 적혀 있어 실제 변경 범위를 빠뜨림.

```bash
git log --all --no-merges --date=short   --since=2026-MM-DD --until=2026-MM-DD   --pretty='%ad %h %s' --author-date-order
```

- `--until` 은 그 주 **일요일 다음날**(경계 배제) 또는 `--until='2026-MM-DD 23:59'`.
- 브랜치 여러 개에 나뉘어 있으므로 `--all` 필수. 머지 커밋은 제외.
- **Done 에 없는 커밋도 전부 훑을 것** — 기록 안 된 수정·되돌림이 그 주 서사의 핵심인 경우가 많음.
- 큰 변경은 `git show --stat <해시>` 로 파일·줄수 확인 후 본문에 반영.
- 커밋 수가 많으면(40+) 본문엔 분류별 대표 해시만, `## 커밋` 표엔 전부.

기간 밖 날짜 항목은 건드리지 않음. 날짜 없는 Done 은 git log 로 추정하되 확신 없으면 그대로 둠.

### 3. 주차 파일 작성

- `docs/주간기록/_TEMPLATE.md` 구조 그대로. 파일명 `2026-W##_핵심주제.md`(주제는 `·` 로 2~4개).
- 2번째 줄에 출처 주석: `<!-- Memo.md Done(MM-DD) + DoList Done + 커밋 N건 기반 이관 작성(YYYY-MM-DD). -->`
- `## 핵심` — ①②③ 번호로 2~4개. **무엇을 왜, 결과·실패 포함.** 실패·되돌린 결정도 씀(W37 "조작 규칙 반전 기록" 처럼).
- `## 주요 작업` — 분류별 `### <분류> (MM-DD, 커밋 N건)`, 항목마다 대표 해시 백틱.
- `## 커밋` — 날짜·해시(7자)·메시지 표.
- 직전 주차 파일(가장 최근 `2026-W*.md`) 한 번 읽고 밀도·어투 맞출 것.

### 4. 이관 후 작업판 비우기

1. `docs/Memo.md` — 주간기록에 들어간 `## Done` 항목 **삭제**. (함정·제약은 `pitfalls.md` 에 있으므로 Memo 에서 따로 남길 것 없음.)
2. `docs/DoList.md` — 주간기록에 들어간 `## Done` 항목 삭제.
3. 삭제 전 주차 파일에 실제로 들어갔는지 항목 단위로 대조. **누락 시 삭제 금지.**

### 5. 인덱스·원장 갱신

- `docs/주간기록/INDEX.md` 표에 행 추가. 빠진 주차 행이 있으면 각 파일 제목에서 채울 것.
- `docs/주간기록/_결정원장.md` — 이번 주에 **설계 결정·역전**이 있었으면만. 새 결정은 §1 해당 표에 행 추가, 뒤집힌 결정은 옛 행을 §2(역전·진화)로 이동(삭제 금지). 없으면 손대지 않음.
- `docs/SPEC_INDEX.md` — 그 주에 마일스톤이 바뀌었거나 `docs/done/` 으로 옮긴 SPEC 이 있으면 표 줄 갱신(끝난 SPEC 은 "완료" 표로 내림), "마지막 갱신" 날짜 수정. 주간기록 본문과 상태가 어긋나지 않는지 대조.
- 월이 바뀌는 주면 `docs/월간정리.md` 에 지난 달 롤업 문단 추가(주간기록이 1차 소스, 여기는 월 단위 요약).

### 완료 후

생성한 주차 파일 경로 · 핵심 3줄 · Memo/DoList 에서 지운 항목 수 · 결정원장 변경 여부 출력.
커밋은 `docs:` 접두사로 별도 1건.
