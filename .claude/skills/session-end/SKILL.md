## Session End

세션 마무리 시 `docs/Memo.md`와 `docs/DoList.md`를 업데이트합니다.

### A. `docs/Memo.md`

1. **읽기** — 현재 Todo / Done 상태 파악
2. **완료 항목 이동** — 이번 세션에서 완료된 Todo 항목을 `## Done`으로 이동, 날짜(`YYYY-MM-DD`) 붙이기
3. **미완료 항목 유지** — 아직 못 한 항목은 `## Todo`에 그대로 두거나 내용 갱신
4. **함정·제약 추가** — 코드·커밋 메시지만으로는 알 수 없는 함정·배경 결정이 있으면 `.agents/rules/pitfalls.md` 해당 도메인 절에 추가 (Memo 에는 쓰지 않음)
5. **Done 은 지우지 않음** — 주간기록 이관·삭제는 `/week-end` 몫 (여기서 지우면 기록 없이 소실)

```markdown
## Todo
- [ ] 설명 (파일:함수 또는 시스템 이름)

## Done
- [x] 설명 — YYYY-MM-DD

```

### B. `docs/DoList.md`

1. **체크된 항목 수집** — `## 1. 에디터 작업` / `## 2. PIE 검증` / `## 3. GitHub / 운영 결정` 안에서
   `- [x]` / `- [X]` 로 체크된 것. 사용자가 직접 체크한 것 + 이번 세션에 클로드가 MCP 로 해결한 것 둘 다.
2. **섹션 전체 vs 개별 항목** — `### 1-N` 절의 체크박스가 **전부** 체크됐으면 절 제목째로 `## Done` 으로 이동.
   일부만 체크됐으면 그 줄만 옮기고 절은 남김(어느 절에서 왔는지 `1-N.` 접두사로 표기).
3. **이동 시 형식** — 제목에 취소선, 괄호에 날짜·주체:
   ```markdown
   - [X] ~~1-15. 대화창 UI 분리~~ (2026-09-21 클로드 MCP 완료) — 무엇을 어떻게 검증했는지 한두 줄
   ```
4. **MCP 로 해결된 항목** — 원래 "사람 몫"으로 올렸던 게 MCP 로 풀렸으면 그 사실을 근거(스크린샷 경로·로그)와 함께 적음.
5. **Done 은 삭제 안 함** — DoList Done 은 기간 만료 정리 없음(Memo 와 다름). 이력으로 남김.

### 규칙

- 완료 항목 **삭제 금지** — Done으로 이동만
- pitfalls.md: 코드가 이미 설명하는 내용은 쓰지 않음. "왜"와 "제약"만
- DoList 에 **새 항목을 추가하지 않음** — 등록은 작업 중에. 여기선 이동·정리만
- 체크 안 된 항목을 "됐겠지" 로 옮기지 않음. 근거(사용자 확인·로그·스크린샷) 없으면 그대로 둠

### 완료 후

Memo 잔여 Todo · pitfalls.md 에 추가한 항목 · DoList 에서 Done 으로 옮긴 항목 목록을 출력합니다.
