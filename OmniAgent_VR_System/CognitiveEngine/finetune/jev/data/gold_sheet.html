NPC 입장에서 지금 가장 자연스러운 활동 1개를 고르고(정답이 하나로 안 정해지면 애매함 — 건너뜀), 펼쳐지는 슬롯을 채운다(비워 두면 default = 게임이 결정). 입력은 이 브라우저에 자동 저장된다. 끝나면 JSON 저장 → finetune/jev/data/gold_answers.json 에 둔다.

검수 모드 — 모델이 고른 활동·슬롯이 미리 채워져 있다. 자연스러우면 그대로 두고, 부자연스러우면 부자연스러움을 체크한 뒤 메모에 이유를 적는다(정답을 알면 활동·슬롯을 고쳐도 된다). 이미 직접 입력한 카드는 그대로 유지된다.
